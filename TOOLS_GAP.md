# TOOLS_GAP — карта инструментов Директа/Метрики: что Борис недоиспользует

Аудит на утверждение владельца. Контекст: B2B-доставка обедов, **Поиск**, Москва+МО, **ручные ставки** (HIGHEST_POSITION), одна кампания 711897777. North star — максимум заявок на рубль.

**Правило проекта:** ничего не внедряем этим документом. Новые **write**-структуры — ТОЛЬКО после пробы на ТЕСТОВОЙ кампании, незнакомую структуру API не угадывать. Разрешённый write-набор сейчас: `keywordbids.set`, `campaigns.update` (минуса на уровне кампании, DailyBudget, ADD_METRICA_TAG), `keywords.suspend`, `campaigns.suspend`. Объявления — только чтение.

**Что Борис уже умеет (база для колонки «статус»):**
READ Директ — `campaigns.get`, `keywords.get`, `keywordbids.get` (со ставками аукциона), `ads.get`, автотаргет-записи, Reports (`SEARCH_QUERY_PERFORMANCE` + `CUSTOM`). READ Метрика — `stat/v1/data` по цели 575665118 (по дням / источникам / utm / посадочным). WRITE — только разрешённый набор выше. Задел — `offline_conversions/upload` (за флагом).

Легенда статуса: 🟢 знает+использует · 🟡 знает, не использует · 🔴 не знает вообще.

Групповой минус режет точечно. | 🔴 не знает (умеет только кампейн-левел) | **Чтение+диагноз сразу, write после пробы.** Влияние **СРЕДНЕЕ-ВЫСОКОЕ** (снимает риск каннибализации, точнее чистка). ## Сводка приоритетов (на утверждение)

**Внедрять первыми (высокое влияние, низкий/средний риск, чтение+диагноз):**
1. **Временной таргетинг** — расписание показов (выходные/ночь). Чтение+диагноз сразу, write после пробы.
2. **Форм-воронка Метрики** (formReachRate по группам) — диагнозы FORM_DROPOFF/AD_TEXT_PROBLEM/BOT_TRAFFIC (backlog #3, только чтение).
3. **Корректировки ставок по устройствам** + device-разрез Reports — чтение+диагноз, write после пробы.
4. **Групповые минус-фразы** + `adgroups.get` — снять каннибализацию; write после пробы.

**Средний приоритет:** операторы соответствия ключей (write после пробы), гео-корректировки, офлайн-конверсии (активировать по данным сделок), device/geo-разрезы Reports, `changes.check`.

**Развилки владельца (крупные, не Борис решает):** переход на оплату за конверсии (смена парадигмы биддинга); создание/A-B объявлений и расширений (креатив).

**Не нужно:** ecommerce, вебвизор-автоматизация, видео/картинки в Поиске, пакетные/сезонные стратегии (на текущем объёме одной кампании).

**Общий принцип:** сначала расширить ЧТЕНИЕ+ДИАГНОЗ (нулевой риск, сразу усиливает мозг и полигон), затем write-инструменты — по одному, каждый через пробу на тестовой кампании, с добавлением в разрешённый набор write-gate только после подтверждения.
